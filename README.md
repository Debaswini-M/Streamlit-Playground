# 🚀 Streamlit Playground


A centralized repository for interactive Streamlit applications, Machine Learning models, and Deep Learning projects.
This repository serves as a deployment-ready sandbox for building, testing, and showcasing production-style ML/DL applications with clean architecture and modular structure.


![Python](https://img.shields.io/badge/Python-3.10+-blue?logo=python&logoColor=white) ![Streamlit](https://img.shields.io/badge/Framework-Streamlit-red?logo=streamlit&logoColor=white) ![Status](https://img.shields.io/badge/Status-Active-brightgreen) ![Deployment](https://img.shields.io/badge/Deployment-Streamlit%20Cloud-orange)



---

## 📌 Purpose

Streamlit Playground is designed to:

- Build and deploy interactive Python web applications
- Integrate Machine Learning models into web interfaces
- Showcase Deep Learning experiments
- Practice model deployment workflows
- Maintain scalable, modular project organization
- Create a portfolio-ready ML application hub

## ⚡ Applications

### Age Calculator [![Age Calculator](https://img.shields.io/badge/Live-App-success?logo=streamlit)](https://agecalculatorpy-an8wqjh5hmd7piez8wsjll.streamlit.app)

**Features**

- Accurate age calculation using `dateutil.relativedelta`
- Automatic birthday detection 🎉
- Celebration animation with `st.balloons()`
- Custom UI styling with gradient overlay
- Non-copyright background image integration
- Streamlit Cloud deployment ready


**Tech Stack**

- Python
- Streamlit
- python-dateutil
